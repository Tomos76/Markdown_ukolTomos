# Recenze filmové série Duna
## Část 1 Představení
Série Duna se převážně odehrává kolem půvabné a podivuhodné planetě **Arrakis**, která je žilou té nejdůležitější surovinou zvanou **Spice**
Zapomocí Spice se dá cestovat vesmírem a říká se, že kdo má kontrolu nad Arrakisem, má kontrolu nad celou vesmírnou ekonomií
Arrakis ale obývají místní obyvatelé zvaní **Fremeni**, pouštní nomádi kteří jsou jedni s planetou. Fremeni ovšem nejsou jediná věc, která planetu obývá.
Pod písečnými dunami se plíží obrovské písečné žížaly, které vnímají každičký pohyb a jsou vždy připraveni zdroj zvuku pohltit.

## Část 2 Vizuál
Planeta je sice celá pokryta pískem, ale je velmi vizuálně podivuhodná.
Prostředím vyvolává pocit volnosti ale zároveň nejistoty
